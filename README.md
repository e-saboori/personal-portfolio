# Personal Portfolio

Static personal profile page scaffolded for GitHub Pages.

## Edit Your Profile

Start by filling out `profile-info.md`. Use it as the source of truth for the content that will go into the site.

## Preview Locally

Open `docs/index.html` in your browser.

## Publish With GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/docs`.
6. Save the settings and wait for GitHub to publish the site.
